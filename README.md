# TaskMiner
TaskMiner: IA que observa por 14 dias o que cada colaborador faz no computador (sem capturar tela), descobre as tarefas repetidas e o Claude gera o manual de processos, gargalos e melhorias. Painel para gestores e equipe. O Executor permite ao Claude operar o computador por comando, com aprovação e travas de segurança.
