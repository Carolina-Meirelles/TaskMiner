Neste computador

Situação: {{ 'Liberado' if ativo else 'Desligado' }}

  1. No computador (Windows, macOS ou Linux), instale as dependências: 
    pip install -r requirements-executor.txt
  2. Abra o executor com o seu código pessoal: 
    python executor.py --servidor {{ servidor }} --token {{ eu.token_coleta or 'SEU_CODIGO' }}
  3. Deixe a janela aberta. Para parar tudo na hora, leve o mouse a um canto da tela ou aperte Ctrl+C no terminal.

Enquanto roda, o Claude vê capturas da sua tela. Por isso o executor se recusa a continuar se uma janela de senha, banco ou navegação anônima estiver aberta.
