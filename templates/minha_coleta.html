Como instalar o agente no seu computador e o que ele registra. Situação atual: {{ st.texto }}

Instalar no seu computador (Windows)

  1. Instale o Python 3.10 ou mais novo em python.org, marcando “Add Python to PATH”.
  2. Copie a pasta do TaskMiner para o seu computador e, dentro dela, rode: 
    pip install -r requirements.txt
  3. Inicie a coleta com o seu código pessoal: 
    python main.py coletar --servidor {{ servidor }} --token {{ c.token_coleta }}
    O código fica salvo: das próximas vezes basta python main.py coletar.
  4. Aceite o termo de consentimento. A coleta dura {{ config_dias }} dias e continua de onde parou se o computador for desligado.

Não compartilhe o seu código: ele identifica você para o servidor. Se ele vazar, peça ao administrador um novo.

O que é registrado

Registrado

  • Nome dos botões e campos clicados
  • Atalhos de teclado, Enter e Tab
  • Quantidade de caracteres digitados
  • Períodos sem uso do computador
Nunca registrado
  • O texto que você digita e as senhas
  • O endereço completo das páginas
  • Capturas de tela
  • Navegação anônima e gerenciadores de senha
  • E-mails, CPFs e telefones em títulos (são mascarados)

Ctrl+Alt+P pausa e retoma a coleta a qualquer momento.
